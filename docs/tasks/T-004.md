## 实际任务包

- 目标仓库：`jeskoky-pixel/amadeus-qq`，开发起点 `e97ae4bb5c043ea2f9b60a1756d7d9ad5b1621c6`。
- 实际执行位置：主项目忽略目录 `private/m0/worker-workspace/`，不是生产 QQ bridge、不是插件工作树，也不把共享 `.git` 交给 worker 写。
- DSH：官方安装包 CLI `0.2.1-rc.3`；开发 home 为独立 `private/m0/dev-home/`。
- 输入：Codex 编写的 `qq-life-v0.1.md` 契约副本和 12 项只读测试，全部为合成数据。
- 输出允许路径：仅 `validate-envelope.mjs`、`RESULT.md`。
- 接口：纯同步 `validateEnvelope(value): string[]`，空数组表示事件 envelope 形状有效；校验版本、必需/可选字符串、四种事件、字段白名单和真实 UTC 日历时间。
- 不涉及：实际鉴权、事件总线、QQ 收发、Life 调度、产品插件安装或平台部署。
- 禁止：子代理、shell、PTC、web、外部 Agent、生产凭据读取、Git 提交、修改测试和契约。
- 权限：workspace-write；approval policy never；不升级为全权限。
- 模型：沿用当前桌面配置的 `opencode-go / deepseek-v4.1-flash`。仅将该开发请求所需的凭据注入子进程环境，不加载生产 profile，不落盘复制凭据，不继承 QQ / GitHub 凭据。
- 时间预算：每次 180 秒，最多一次修订；实际初稿 79.08 秒，修订 75.58 秒。

## 分派与监督

使用已安装 dsh-delegator 技能的 headless wrapper。原技能附带的日志解码器为 CPython 3.11 ABI，与本机 Python 不匹配，预检报 WATCHDOG_UNAVAILABLE，尚未启动 DSH。随后在私有目录复制 wrapper，使用 DSH 捆绑 Python 3.12.14 和隔离安装的 zstandard 0.25.0；没有修改原技能。

初稿 wrapper SUCCESS / 退出 0，但 Codex 执行测试发现语法错误，拒绝接受。Codex 通过同一个 `--session-id` 进行一次修订；修订使用 `--json`，退出 0，两轮持久 turn/end reason.kind 均为 completed。该安装版 JSON final 帧只有 text，没有 reason，故未照抄规格示例中并不存在的字段。
